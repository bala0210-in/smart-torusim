## Quick Start Guide

### 1. Start the Backend Server (Express + Node.js)
```powershell
cd server
npm install                                        
npm start
```
*API running at: `http://localhost:5000/api`*

### 2. Start the Frontend Client (React + Vite + Tailwind CSS)
In a new terminal:
```powershell
cd client
npm install
npm run dev
```
*Application live at: `http://localhost:5173`*

## Innovation Highlights

- **Smart Crowd Advisor & Load Balancer:** Automatically diverts traffic from congested tourist traps (Ooty, Jaipur, Manali, Goa) to tranquil hidden gems and artisan families.
- **Sustainability & Community Score (0–100 🌱):** Real-time measurement of direct village economic impact.
- **AI Travel Experience Planner:** Synthesizes customizable day-by-day itineraries tailored to budget, days, and cultural passions.
- **Digital QR E-Pass:** Generates instant printable passes for seamless village check-ins.
- **Emergency Safety Assistance (SOS):** 1-tap emergency broadcast and national helpline routing.
